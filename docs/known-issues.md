# Ловушки

- Next.js 16 отличается от знакомых версий. Перед кодом смотреть node_modules/next/dist/docs/. `next dev` сам дописывает блок в AGENTS.md: это нормально, коммитить вместе с работой.
- Токены живут в двух местах: DESIGN.md (корень) и src/app/globals.css. Меняешь один, меняй и другой.
- Корейский внутри русского текста может рваться на узком экране. Проверять на ширине 320 px.
- Правки в корне (DESIGN.md, PRODUCT.md, .impeccable/) не видны в git diff.
- Две сессии Claude уже правили одни файлы параллельно. Перед правками смотреть git -C korean-threads-app status.
