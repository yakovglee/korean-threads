# 문법 · Грамматика — спецификация первой версии

Составлено 1 ноября 2026 года по итогам интервью (grill-me, вопросы Q1–Q38). Термины — из [GLOSSARY.md](../GLOSSARY.md), ключевые решения с обоснованием — в [docs/adr](adr/).

## Зачем

Админ учит корейский, у него есть библиотека учебников и официальные экзамены TOPIK. Нужно место, где можно быстро спросить про грамматику и получить ответ живым языком в формате коротких постов, с опорой на свои учебники, со словарём под рукой и с тренировкой на настоящих заданиях TOPIK.

## Кто пользуется

- Админ и его друзья, это небольшой круг. Вход по ссылке на почту, только для адресов из списка доступа.
- Лента приватная: каждый ученик видит только свои треды ([ADR 0001](adr/0001-private-linear-threads.md)).

## Треды и ответы

- Ученик пишет вопрос, бот отвечает тредом из 3–6 коротких постов: цепляющий первый пост, правило, примеры, частые ошибки. Посты появляются по одному, как будто бот печатает.
- Тред линейный: уточнение уходит в конец треда, конкретный пост можно процитировать. Бот учитывает весь тред.
- О чём можно спрашивать: любые вопросы о корейском — грамматика, разница между похожими конструкциями, лексика, естественность фразы — и проверка предложения. Вопросы не про корейский бот вежливо отклоняет одним постом.
- Ученик может удалить свой тред.

## Тон бота

- Ответы по-русски, корейские примеры с переводом.
- На «ты», 1–2 эмодзи на пост, лёгкий юмор и живые примеры из жизни в Корее, без сленга ради сленга.
- Персонажа нет, аккаунт подписан «문법 · Грамматика» и имеет простую аватарку.
- Интерфейс на русском.

## Ученик и уровни

- При первом входе ученик выбирает уровень (초급 / 중급 / 고급), позже его можно поменять в профиле.
- От уровня зависят глубина объяснения и сложность примеров. Романизация показывается только на 초급.

## База знаний и источники

- В базу знаний входят: `GRAMMAR_MAIN.md` (каталог конструкций, база 한국어교수학습샘터), Korean Grammar in Use 1–3, `korean_grammar.md`, оба курса Вон Гван, NIIED 초급 и 중급, KIIP 1–4.
- Три сторонних TOPIK-сборника исключены совсем ([ADR 0004](adr/0004-official-topik-only.md)).
- Поиск идёт по смыслу (эмбеддинги в Supabase pgvector). Модель эмбеддингов выбирается сравнением двух кандидатов через OpenRouter (например, qwen3-embedding-8b и bge-m3) примерно на 20 тестовых вопросах.
- Под тредом блок «📖 Источники»: книга и страница, по нажатию раскрывается цитата. Номера страниц — это номера страниц PDF, они могут не совпадать с напечатанными.
- Если в учебниках ничего не нашлось, бот прямо говорит: «в твоих учебниках этого нет, объясняю по общим знаниям».

## Словарь и разбор слов

- Словарь — 한국어기초사전 через krdict Open API:
  - запросы `search` и `view`, ответ в XML;
  - перевод на русский: `translated=y&trans_lang=10`;
  - лимит 50 000 запросов в день.
- Бот сверяется со словарём в вопросах о словах и указывает источник «📖 한국어기초사전».
- Любое корейское слово в постах (и бота, и ученика) нажимается и открывает карточку слова: русский перевод, уровень, произношение, пример и ▶, если в словаре есть запись произношения.
- Словарную форму даёт морфологический разбор (mecab-ko-fastapi админа) один раз при сохранении поста: 먹었어요 → 먹다, 공부했어요 → 공부하다, 도와요 → 돕다 ([ADR 0006](adr/0006-mecab-service.md)). Частицы и окончания в первой версии не нажимаются.
- Ответы словаря кэшируются в Supabase.
- У тредов о словах есть тег слова (`단어: 기대하다`).

## Квизы

- Квиз появляется один раз на тред, в конце первого ответа, и подбирается по тегам треда. Если тегов нет, квиза нет. Кнопка «ещё вопросы» выдаёт новые задания.
- Состав квиза: 2–3 задания на чтение и 1 задание на аудирование, если для этой конструкции оно нашлось. По желанию добавляется задание «своё предложение», его проверяет бот.
- Задания TOPIK берутся из официальных экзаменов в `books/TOPIK`: 35, 36, 37, 41, 47, 52, 60, 64, 83, 91, 96 и 102-й, TOPIK I и II.
  - Чтение — из всех экзаменов.
  - Аудирование — из 83, 91, 96 (только TOPIK II) и 102-го.
- Правила подбора — в [ADR 0005](adr/0005-topik-task-matching.md):
  - задание на чтение подходит, если прямо проверяет конструкцию;
  - задание на аудирование подходит, если конструкция звучит в скрипте;
  - если ничего не подошло, бот составляет сгенерированное задание с пометкой.
- Формат: 4 варианта ответа, сразу видно, верно ли, и короткое объяснение. Для задания TOPIK указан источник: «📝 TOPIK 64회 읽기 №3».
- Аудио можно переслушивать сколько угодно. После ответа показывается скрипт с выделенной конструкцией.
- Попытки сохраняются, на их основе позже появится «повторить ошибки».
- Подготовка заданий:
  - PDF экзаменов — это сканы без текстового слоя, их нужно распознать (OCR на Apple Vision, см. ниже);
  - каждое задание связывается с ответом из ключа (정답표) и получает теги конструкций из каталога; эта разовая обработка идёт через модель OpenRouter.
- Аудио нарезано по заданиям (31 трек на TOPIK I, 51 на TOPIK II). Его нужно пережать встроенным `afconvert` в моно AAC: по оценке получится около 100 МБ, в бесплатное хранилище Supabase помещается с запасом.

## Навигация

- Теги: конструкция и уровень по каталогу конструкций, а также слова. Ленту можно фильтровать по тегу и уровню.
- Закладки ставятся на отдельные посты, для них есть отдельная вкладка «Закладки».
- Поиск работает только по своим тредам (вопросы и ответы), по точным словам (`-더라고요`) и по смыслу («как сказать, что я это видел сам»).

## Модели, админка, расход

- Всё идёт через OpenRouter: ответы и эмбеддинги одним ключом ([ADR 0002](adr/0002-openrouter.md)).
- Админ задаёт список разрешённых моделей и модель по умолчанию (Claude Sonnet 5.5). Ученик выбирает модель в настройках.
- Лимитов нет. В админке видно, сколько каждый ученик потратил за месяц и на каких моделях; стоимость каждого ответа сообщает OpenRouter.
- Админка видна только админу: список доступа, модели, расход.

## Стек и инфраструктура

- Next.js (веб, удобно с телефона, PWA) на Vercel Hobby, исходники в приватном репозитории GitHub.
- Supabase cloud на бесплатном тарифе: Postgres, pgvector, Auth (вход по ссылке на почту), Storage для аудио.
- Локальная разработка через Docker и Supabase CLI.
- AI SDK вместе с провайдером OpenRouter. Стоимость приходит в `providerMetadata.openrouter.usage`; в потоковом режиме её нужно запрашивать явно.
- Учебники и TOPIK в репозиторий не попадают, индексация идёт локальным скриптом прямо в Supabase ([ADR 0003](adr/0003-books-outside-repo.md)).
- Репозиторий — вся папка `claude-korean` (приватный GitHub), `books/` исключена через `.gitignore`. Код приложения лежит в `app/`, документы и скиллы проекта — в корне.
- Морфологический разбор — mecab-ko-fastapi админа, отдельный проект. Приложение обращается к нему по URL от админа, только с сервера ([ADR 0006](adr/0006-mecab-service.md)).
