# Квизы только из официальных экзаменов TOPIK

В `books/md` лежат три сторонних TOPIK-сборника (`All_Kill_33`, `TOPIK_II…`, `topik test.md`), но в приложение они не попадают: ни в базу знаний, ни в квизы. Задания TOPIK берутся только из официальных экзаменов в `books/TOPIK`: 12 сессий, около 2000 заданий с ключами ответов. В официальных экзаменах нет ошибок распознавания и неточностей сторонних изданий, а в базе знаний тестовые задания вытесняли бы объяснения.
