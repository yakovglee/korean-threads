# Модели через OpenRouter, а не напрямую через Anthropic API

Ученик сам выбирает модель из списка, который задаёт админ (по умолчанию Claude Sonnet 5.5). Поэтому и ответы, и эмбеддинги идут через OpenRouter: один ключ даёт модели разных провайдеров, а в каждом ответе есть его стоимость — на ней держится статистика расхода. Лимитов на расход нет, админ видит только статистику.
