# Морфологический разбор: отдельный сервис админа mecab-ko-fastapi

Чтобы любое корейское слово в посте открывало карточку слова, нужна его словарная форма (먹었어요 → 먹다, 도와요 → 돕다). Её даёт сервис админа [mecab-ko-fastapi](https://github.com/yakovglee/mecab-ko-fastapi) на MeCab-ko. Это отдельный проект: его деплоит и сопровождает админ, а приложение обращается к нему по URL, который даёт админ, и только со своего сервера. Код сервиса в репозиторий приложения не попадает (лицензия GPL-2.0, поэтому разбор остаётся отдельной программой). Разбор делается один раз при сохранении поста.

## Considered Options

- Бот сам размечает слова в постах: ненадёжно и покрывает только часть слов.
- Python-функция в том же проекте Vercel, что и приложение (копией кода или git submodule): отклонено админом.
- Docker-контейнер на Render или Fly.io, Google Cloud Run: хостинг сервиса — выбор админа.

## Consequences

Приложение зависит от доступности этого сервиса. Если он не отвечает, пост всё равно сохраняется, но слова в нём не нажимаются, пока разбор не повторят. Сейчас у сервиса открыт CORS (`*`) и нет проверки ключа, так что защищать его от чужих запросов — на стороне админа.
