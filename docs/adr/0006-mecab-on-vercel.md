# Морфологический разбор: свой mecab-ko-fastapi как Python-функция в проекте Vercel

Чтобы любое корейское слово в посте открывало карточку слова, нужна его словарная форма (먹었어요 → 먹다, 도와요 → 돕다). Её даёт сервис админа [mecab-ko-fastapi](https://github.com/yakovglee/mecab-ko-fastapi) на MeCab-ko. Сервис работает как Python-функция в том же проекте Vercel, что и приложение, поэтому новый хостинг и аккаунты не нужны. Разбор делается один раз при сохранении поста.

Код сервиса в репозиторий приложения не копируется, источником остаётся репозиторий админа (лицензия GPL-2.0, поэтому разбор остаётся отдельной программой). Для работы на Vercel нужны три правки: `Tagger` создаётся один раз, добавляется проверка секретного ключа, код адаптируется под Vercel.

## Considered Options

- Бот сам размечает слова в постах: ненадёжно и покрывает только часть слов.
- Docker-контейнер на Render или Fly.io.
- Google Cloud Run: нужна карта в Google Cloud.
- Копия кода в репозитории приложения: отклонено админом.

## Consequences

Пока не проверено, запускаются ли бинарники MeCab и словарь на Python-рантайме Vercel; это первый шаг реализации. Если не запускаются, решение пересматривается вместе с админом; запасной вариант — Render.
