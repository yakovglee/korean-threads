# Korean Threads

Личная мобильная лента корейских постов для подготовки к TOPIK II (4급, февраль 2027): любое слово раскрывается касанием, в ленте изредка встречаются мини-проверки, есть чат. Сейчас сделан экран ленты на демо-данных, бэкенда пока нет.
Работаем по схеме «Мозг и руки» (исходник в ../super-claude/): дорогая модель думает и проверяет, дешёвые пишут код.

## Как ты работаешь
- Ты оркестратор. Планируешь, пишешь задания, принимаешь работу.
  Код сам не пишешь: отдаёшь агенту builder. Исключение: правка в одну-две строки.
- Все субагенты по умолчанию идут на Haiku: builder, reviewer, поиск, исследование. Им параметр model не передаёшь.
- Исключение: /impeccable целиком работает на сильной модели. Его правки кода и вида делаешь сам, builder не зовёшь.
  Его субагентов (оценки A и B в критике, финальное ревью) запускаешь универсальным агентом с параметром model: "opus". Без него они уйдут на Haiku. builder и reviewer для impeccable не используешь.
- Задание для builder не длиннее 10 строк, по шаблону:
  Цель: что сделать, одним предложением.
  Прочитай: какие файлы.
  Не трогай: какие файлы.
  Done when: команда, которую можно запустить, и что она должна показать.
- Независимые задания, которые не трогают одни и те же файлы, можно отдавать нескольким builder одновременно.
- Перед приёмкой сам запускаешь команду из Done when. Докладу builder на слово не веришь.
  Если задача меняет вид или поведение экрана, сам проверяешь в браузере (dev-сервер из .claude/launch.json, порт 3100): у builder браузера нет.
  Не прошла: возвращаешь задание builder с выводом ошибки. После трёх возвратов остановись и спроси меня.
- Когда вся задача принята, вызови reviewer: передай ему задания и попроси сверить изменения.
- Начало сессии: прочитай docs/progress.md и docs/known-issues.md.
- Конец задачи: допиши строку в docs/progress.md. Новое решение запиши в docs/decisions.md, новую ловушку в docs/known-issues.md.
- Условие готовности задаю я. Если в задаче его нет, предложи команду или проверку и дождись согласия до начала работы.
  Папка acceptance/ (когда появится) это условие готовности от меня. Не меняй её сам и не давай менять builder.
- Коммиты только по моей просьбе.

## Карта папок
- PRODUCT.md, DESIGN.md: продукт и дизайн-токены. Их читает /impeccable, поэтому они в корне репозитория
- specs/korean-threads/: PRODUCT.md (пункты «П-N»), TECH.md (архитектура и решения)
- docs/superpowers/: дизайн-спек и пошаговый план plans/2026-11-14-korean-threads.md (список задач «Task N»)
- docs/progress.md, decisions.md, known-issues.md: память проекта
- .impeccable/: контракт экрана ленты (surfaces/feed.md) и снимки ревью (review/, не в git)
- src/app/: маршруты (/ владелец, /viewer зритель), layout.tsx, globals.css
- src/components/: Feed, ThreadCard, KoText, WordSheet, QuizCard, ChatBar, TopBar
- src/lib/demo-data.ts: синтетические данные ленты
- Вне репозитория: ../books/ (книги, TOPIK, OCR; скрипты берут путь из KB_SOURCE_DIR, в git не класть), ../super-claude/ (исходник схемы, не трогать)

## Команды
- npm run check: типы и линтер
- npm run build: продакшн-сборка
- npm run dev -- -p 3100: dev-сервер (то же в .claude/launch.json)
